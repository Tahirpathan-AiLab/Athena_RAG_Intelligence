# Code Description

This project is an **AI-powered document intelligence platform** built using **Retrieval-Augmented Generation (RAG)** to deliver accurate, context-aware answers from user-uploaded documents. It combines semantic search, vector embeddings, conversational AI, and a modern web interface to create an intelligent knowledge management system.

### Overview

The project begins with a document upload system that allows users to upload PDF documents through a drag-and-drop interface or file picker. Uploaded documents are automatically processed, divided into semantic chunks, converted into vector embeddings, and indexed for intelligent retrieval.

The chat interface enables users to ask questions in natural language. Instead of relying only on the language model, the system performs semantic similarity search to retrieve the most relevant document chunks before sending the context to the **Grok** language model. Every generated response includes **source citations** and **similarity scores**, improving transparency and reliability.

Athena also includes a dedicated **Knowledge Base** for browsing indexed documents, a **Voice Assistant** with an animated FluidGlob interface, and an **Analytics Dashboard** for monitoring documents, embeddings, storage usage, query trends, and response performance.

The frontend is built with **React** and **Vite**, while the backend is powered by **FastAPI**, creating a scalable and modular architecture. Features such as document management, persistent chat history, theme personalization, and configurable API integration make Athena suitable for modern AI-powered knowledge management applications.
